### 2026.10.4 选中敌人
1. 玩家现在可以左键选中**敌对单位 / 敌对建筑（只能单个选中）**，地图上照常画选中圈 / 金色外框
2. 选中敌人时右下角**不给任何页签**：只立一颗空格子（`PAGE_NONE`），命令卡也是空的 —— 不会对着敌人的建筑弹出「升级」、也不会给敌人的区划做特化
3. 右栏报敌人的名称与数值（血量 / 兵种 / 攻击力 / 攻击距离间隔，建筑另有伤害射程），**不出现任何己方动作文案**
4. 实现上单开 `input_controller.selected_enemy` 一个字段（而不是塞进己方选中集合）：己方那条链（队伍展开 / 部队列表 / 招募 / 命令卡）天然看不到敌人，杜绝「给敌人下自己的命令」
5. 顺带修了两处：点**别人区划**的中心不再打开区划详情（改走「选中敌对建筑」）；选中敌人后它被打死或被迷雾盖住时选中自动断开
6. 敌人的选中走**战争迷雾**：看不见的敌人点不到（与右键点名的口径一致）
