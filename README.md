   **默认取第一个可玩阵营（F1）**；

### 2026.10.18 手机端性能第二轮（尖峰修复 + C# 视野内核）
1. **HUD / 小地图周期性尖峰**：HUD 改 4 槽调度（shell / 详细信息 / 部队列表分摊到不同节拍），
   选中变化立即全刷；详情文本、头像、3×3 网格、招募队列都加了「内容没变不重排」；
   小地图降到 10Hz 并错开 HUD 槽位；
2. overlay 网格 / 区划轮廓 / 占领触发区改成**屏幕坐标缓存**（相机静止不重投影）；
3. 小地图迷雾烘成贴图；战争迷雾的扇区 / 山脉视线 / 掩码合并下沉到
   **C# `logic/FogKernel.cs`**，保留 GDScript 回退与逐字节等价测试；
4. 手机端默认 **vsync off + `Engine.max_fps = 60`**；
5. 真机读数：`fr 15.3 (11.1~16.7)ms`，`rest 7.8 → 3.4ms`，周期性尖峰消失；
6. 测试：48 文件 / 5776 项断言全绿。细节见 `dev_gd_a/docs/mobile.md` 第 12~17 节。

### 2026.10.18 手机端操作手感修复（悬停 / 反馈 / 框选 / 读数）
1. **长按按钮后移开手指，金色填充一直留着** → 触摸抬起时延迟一帧清掉整层悬停
   （`start_screen._input`，主菜单 + 战役页；局内的 HUD 见第 6 条），桌面鼠标不受影响；
2. **点按钮「立刻满格、随后自己退回去」** → 按下态不再用实心金（改成只加亮描边），
   点开面板的那颗入口按钮**锁在满格**，按「返回」收起面板时才解除 ⇒
   正向填充 / 反向渐出的两段动画；
3. **双指框选右上、左下两个角不跟手** → 选框改成按**两指定义的屏幕矩形**画
   （透视下世界矩形的远端边会缩进）；
4. **性能读数瘦身** → 默认只显示 `FPS`，位置移回**最左上角**；完整 4 行分段读数
   收进 `ui.show_perf_detail`（默认关，排查时再开）；
5. **框到了单位却有概率没选中（连带整支部队）** → 框选的**判定**改成按屏幕矩形、并且判
   **立牌图标的屏幕矩形**（不是脚底锚点）；**PC 与手机端统一走这条路**（PC 的框也改画屏幕矩形），
   整队展开仍在 `select_units` 里；
6. **游戏内按钮手指移开后仍满填充** → `hud.handle_touch` 抬起时延迟一帧清整棵 HUD 的悬停；
7. **按下兜底** → 确认按下（`pressed`）那一下，背景**瞬间**顶到满格（只顶当前值、不改目标），
   快速点按也一定有满格反馈；
8. 测试：48 文件 / **5828** 项断言全绿（本轮 +52）。细节见 `dev_gd_a/docs/mobile.md` 第 18、19 节。
