### 战役模式 / 关卡覆盖层 / 共享视野（本轮）

1. 新增**战役数据格式**：`data/campaigns/<id>/campaign.json` + `levels/*.json`，**一关 = 一张地图 + 一层覆盖**。地图文件（地形 / 区划 / 产能 / 大本营）一个字都没改，关卡只拥有这一关专属的东西：玩家席位（1~2 个）、每一方挂什么 AI、**往哪打**、开局摆放、目标与额外失败条件。加一个战役 = 放一个新目录，代码与配置一个字都不用改。
2. **「红点波次」= 给挂阵营 AI 的那一方指定进攻目标**（`attack_target`：`zone` / `point` / `building` / `base`；不写就退回「打最近的敌方区划」）—— **不做触发器、不做时间轴**：现有的「招将 → 招兵 → 满员 → 行军攻击 → 被打光再重招」循环本身就是一波又一波。出兵那一下会发一条 `ai_attack_launched`，底栏播报「边军出兵了」。
3. **目标与胜负**：只做「守住指定区划 N 秒」；★ **目标区划一丢掉就当场判负**（连暂停都没有）；守满的那一帧立刻判胜；玩家同方的**大本营全部被拆**常开判负（拆一半不算）；额外失败条件第一批只有「指定区划失守」。
4. **AI 改成按阵营挂**（阵营性 / 将领性 / 不动 + `resource_mult` 难度旋钮 + 该方自己的 AI 参数），并且 ★★ **玩家选中哪一方，运行时就把那一方的 AI 摘掉**。
5. **合作的地基**：迷雾改成**按同方**分桶 ⇒ 同一方的两名玩家**共享视野**（没结盟的第三方照样看不到）；玩家资源从「一个字典」改成**按席位**（本机席位那一份就是 `world.resources` 这个对象本身，HUD 与扣费天然同一份数）。
6. 样例战役 `data/campaigns/demo`（东征·第一章：单人守中场 + 双人合作双子防线），引用一张 `hidden: true` 的**战役专用图** `data/maps/dongzheng/`（不进自由对战的选择条、也不当默认图）。
7. **战役编辑器**（`dev_gd_a/tools/campaign_editor/`，Python + tkinter、零依赖、双击 `campaign_editor.bat`）：五个页签 **战役 / 关卡 / 阵营与 AI / 摆放 / 校验与导出**。★ 摆的是**关卡层**（开局摆放 + 出生点 + 目标区划高亮 + 进攻目标箭头），地形 / 区划 / 中心从地图读出来当背景；要改地形点「**打开地图编辑器**」（= `map_editor --map <id>`，为此给地图编辑器加了 `--map`）。导出前跑 **18 条校验**，有拦截项就不许写文件。其断言 `test_model.py` 223 项 + `test_app.py` 99 项全过。
8. **单人战役的占位图形入口**：主界面 `test` 按钮**下面**多了一颗 **`campaign_test`** —— 点它进「单人战役」页（列**单人**关 + 选阵营 + 开始），按「开始」走的是**真正的战役路径**（`World.create_from_level`），所以能直接手玩验战役：进的是 `dongzheng` 那张战役图、自己的将领已在镜头里、边军 AI 会招将招兵出兵。★ 这一版**还没有**正式入口那一套（战役选择条 / 关卡进度 / 简报 / 关卡内目标面板 / 合作大厅），所以合作关在这条路上进不去。
9. ★ **修掉「进场一片紫」**：战役用自己的阵营 id（`F1`/`E1`），而配色表里只有内置 id（`p1`~`p8`/`enemy`/`ai`）—— 没写颜色时引擎会退到**品红**，于是「每个区块底色 + 敌方单位」全是紫的（玩家的原话：「右侧紫色的单位还会攻击我」——那是敌军，颜色错了而已，行为一直是对的）。现在：①`campaign.json` 与关卡 `factions[]` 都带 `color`（F1 青蓝 / E1 红）；②运行时按关卡数据**登记**阵营颜色（`cfg.register_faction_color()`）；③还是没颜色就按内置配色兜底**并警告**；④战役编辑器新增警告 `faction_no_color`，导出前就提示。
10. 新增无头断言 `tests/test_campaign.gd`（239）、`tests/test_outcome.gd`（70）、`tests/test_campaign_ai.gd`（98）、`tests/test_ai_target.gd`（44）、`tests/test_campaign_test.gd`（70），并把 `test_fog.gd` 从 127 扩到 142 项；**全量 34 套 / 4807 项全过**。规划书见 `dev_gd_a/dev_plan_7.md`，口径见 `dev_gd_a/docs/route.md` 第三十七节。

### 2026.9.29 AI 更新

1. 加入两种 AI：**阵营性 AI**（附属在某个阵营下、有自己的资源库，资源随占领区划产出增长，按「招将领 → 让将领招兵 → 升级建筑 → 满员后行军攻击敌方区划」的优先级花钱，资源获取倍率可调难度）与**将领性（防御性）AI**（附属在某个将领下、没有资源库与大本营，在归属区划里按间隔巡逻、警戒到敌人会打但不追出一个区划、脱战 10 秒且不满员时无消耗招兵）
2. 两种 AI 的数值与开关全部在 `data/config.json` 的 `ai` 段；玩家与 AI 的**资源库彻底分开**（谁下单扣谁的钱）
3. 新增无头断言 `tests/test_ai.gd`（133 项）；`World.create()` 多一个 `with_ai` 开关，测试/基准走「不带 AI 的干净世界」
