## 怎么跑

```powershell
# 一键跑完全部无头测试（靠退出码判定成败）
powershell -ExecutionPolicy Bypass -File tools/run-tests.ps1

# 只做语法 / 编译检查（比跑测试更早、更准地报行号）
powershell -ExecutionPolicy Bypass -File tools/check-syntax.ps1

# 装中文字体（每台机器跑一次；不装则 HUD 里中文显示成方框）
powershell -ExecutionPolicy Bypass -File tools/setup-font.ps1

# 用编辑器打开工程
& 'C:\D\GodotEngine\Godot_v4.7.2-stable_win64_console.exe' --path . --editor

# 直接跑游戏（不导出 exe）
& 'C:\D\GodotEngine\Godot_v4.7.2-stable_win64_console.exe' --path .
```

> `tools/` 里的 `.ps1` **只用 ASCII 书写**（中文 Windows 的 PowerShell 5.1 会把无 BOM 的
> `.ps1` 当 GBK 解码并直接解析失败）。中文说明在 [`../daeem/tools/README-tools.md`](../daeem/tools/README-tools.md)，
> 原因见 [`pitfalls.md`](pitfalls.md) 4.4。

## 三句话记住本轮的取舍

1. **纯 2D、只做单机**，但逻辑层现在就分出「命令 / 快照」边界，为第 1 轮的互联网联机铺路。
   本轮**没有写一行联机代码**，但 `command_processor` / `snapshot` 已经就位并有测试。
2. **逻辑与渲染分离**：`logic/` 是纯 `RefCounted`（不碰场景树、不读输入），`view/` 只读状态 + 发命令。
   代价是多写一层同步代码，回报是逻辑能无头跑（997 项断言靠的就是这个）。
3. **数值全进 `data/config.json`**，地图全进 `data/map_01.json`；代码里不写字面量。

## 操作方式（与 HTML 版一致）

| 操作 | 说明 |
|---|---|
| `1` / `2` / `3` | 快速选中三个将领（并把镜头移过去） |
| 左键 | 选中将领 / 建筑；`Shift` + 左键多选 |
| **右键单击敌人 / 敌方建筑** | **优先攻击它**（一路追上去打，不受追击上限约束；建筑是先靠近再拆） |
| **右键双击**任意位置 | **行军攻击**（等价 SC2 按 A）：走到该点，路上遇敌就停下来打，打完了继续走 |
| 右键单击空地 | 命令选中单位移动到**鼠标所指的位置**（点到哪走到哪；点到山 / 敌方城墙时自动走到最近可达处）。**遇敌不停**，且会中断当前交战 |
| （自动） | **警戒**：单位静止且没有目标时自动索敌并主动接敌，不需要玩家操作 |
| **左侧「部队」列表** | 点一行 = 选中那支队伍（只选中，**镜头不动**）；空槽显示「…」且点了没反应 |
| **命令卡（右下 3×3）** | 内容随右侧页签切换：**建筑页** Q=城墙 / W=箭塔（进建造模式，再点一次退出），**单位页** Q=占位单位（招募，在选中将领身旁生成 1 兵） |
| **页签（单位 / 建筑 / 科技）** | 单位、建筑用来切命令卡；**科技本轮点不动**；右上角**设置**也点不动 |
| `B` / `T` | 进城墙 / 箭塔建造模式（与命令卡的 Q / W 同一条路），左键放置，右键或 `Esc` 退出 |
| `X` / `Delete` | 拆除选中建筑（大本营不可拆） |
| **方向键** | 平移视野 |
| 鼠标推到屏幕边缘 | 滚屏（鼠标停在**可点的 UI 控件**上时不会滚） |
| 滚轮 | **以光标为锚点**缩放；`F` 适应视野；`Home` 回大本营 |
| `N` / `P` / `E` / `G` | 显示隐藏区块名 / 暂停 / 刷一个测试敌人 / 坐标调试准星 |

> ⚠️ `W` / `A` / `S` / `D` **不再平移镜头** —— 它们被命令卡的九个格子占用了
> （否则「建筑页按 W 建箭塔」和「W 向上平移」会打架，见 [`route.md`](route.md) 9.3）。

## 手玩验收清单（自动化测试覆盖不到的那部分）

逻辑已由 997 项断言覆盖，**画面与手感**要到编辑器里跑一遍（`--editor` 或直接 `--path .`）：

- [ ] 地形颜色与 HTML 版一致；山地一眼能看出来；能看到 6×4 的区块轮廓与 A1~D6 的名字
- [ ] **UI 按参考图落位**：左侧部队 1~10、左下 400×400 的「地图」占位、底栏 1030×240 的详细信息、
      150 宽的阵营占位、右下 3×3 命令卡、单位/建筑/科技三颗按钮、右上角的设置
- [ ] **选中单位时没有攻击 / 警戒范围圈**（只有单位本身的高亮与攻击线）
- [ ] **详细信息栏**：左栏只有选中对象的信息（没选中就是「未选中」），右栏只有「阵营 + 粮食 + 黄金」；
      开场没有任何提示文案，也没有事件日志
- [ ] **部队列表**：3 支队伍各占一行并显示「部队N　将领 X · N 人」；第 4~10 行是「…」；
      点一行会选中整队（**镜头不动**），空槽点了没反应
- [ ] **命令卡随页签切换**：单位页只有 Q=占位单位；建筑页 Q=城墙 / W=箭塔；
      切到「科技」什么都不变（点不动）；右上角「设置」也点不动
- [ ] **招募**：先选中将领（按 1/2/3），再点命令卡的 Q（或按 `Q`）→ 将领身旁多出一个兵
      （现在**没有日志可看**，只能看单位本身与部队列表的人数变化）；**没选中将领时按 Q 不生成单位**
- [ ] **相机**：方向键能平移；鼠标推到屏幕边缘能滚屏；鼠标停在命令卡/页签/部队行上时**不滚**
- [ ] `W` / `A` / `S` / `D` 只走命令卡，**不再**平移镜头
- [ ] 滚轮缩放（**光标底下的地面不动**）、`F` 看全图、`Home` 回大本营
- [ ] 按住空格时暂停边缘滚屏
- [ ] 按 `G` 打开准星：红叉与绿圈**必须重合**（不重合 = 坐标换算坏了）
- [ ] 按 `1`/`2`/`3` 选中将领，右键点哪走哪；开阔地走直线，绕山时保留拐点
- [ ] **攻击命令**：把镜头拖到地图东侧的对家据点，选中将领后
      **右键单击**守军或箭塔 / 城墙 → 它会一路冲上去打（左栏出现「指定攻击 / 指定拆除」）；
      **右键双击**一块空地 → 红圈加叉的标记出现，单位走过去、路上遇敌就停下来打，打完继续走
- [ ] **点名拆建筑不会被旁边的敌人带跑**（修过的 bug）：先让一个守军站在箭塔旁边，
      再右键点那座箭塔 —— 哪怕守军一直在打它，它也应当**只拆箭塔**，拆完才恢复自动索敌
- [ ] **索敌建筑**：把将领停在对家箭塔 / 城墙 4 格内、附近没有敌方单位时，它会自己开始拆
- [ ] **本体居中**：大本营与箭塔在格子里**居中**、比一格小一圈（城墙仍是整格）
- [ ] **地图预置的守军**：东侧据点的 4 个守军原地不动（靠近才迎战）；另 2 个巡逻兵会朝你的据点推进
- [ ] **占领读条（完整规则）**：
      ① 只有你的单位站在无主区块里 → 进度条 4 秒读满、区块归你；
      ② 让你的单位和敌人**同时在**同一区块里 → **谁都读不了条**：正在读的那条**当场冻住**
      （条上会多一圈白描边，值不再变化）；
      ③ 把那支敌人的兵清掉（或让它走出去）→ 那条进度**缓慢回落**（0.125/秒，约 8 秒退完，
      能明显看出比读条慢得多）；退到 0 之后才轮到另一方开始读；
      ④ 已有的地块被对家读条 → 读满就易主；你的兵杀回去 → 对方的条立刻冻住
- [ ] **同一时刻只会有一条进度条**（不会两条并排，也不会在两方之间来回跳）
- [ ] 点将领（或它的任一亲兵）会**整队**被选中；右键移动时整队一起走；左下栏显示「队伍：将领 1 + 3 名亲兵」
- [ ] **整队点到同一个点**：到达后应当各自散开站定、**不再抖动或原地打转**
- [ ] **建筑本体**：大本营与箭塔居中、明显比一格小一圈；**己方可以直接站到大本营本体上**；
      敌方会贴着本体停下 / 绕开，不会与本体重叠；两座箭塔之间留出的缝能挤过去
- [ ] 点山 / 对家城墙时，单位走到最近的可达处而不是原地不动
- [ ] 按 `E` 刷测试敌人：它朝大本营推进（会绕开玩家的箭塔）；被城墙拦住时**贴到墙边一下一下拆**；拆穿后走进来
- [ ] 将领静止时自动迎战（头顶出现交战三角、画攻击线、掉血有血条）
- [ ] 站进无主区块 4 秒占领成功（进度条从下往上填），资源按己方地块数增长
- [ ] `B` / `T`（或命令卡的 Q / W）建城墙与箭塔；箭塔会打射程内最近的敌人，不误伤己方
- [ ] 中文正常显示（不是方框）；没装字体时跑 `tools/setup-font.ps1`

## 本轮已知限制（有意不做）

| 限制 | 说明 |
|---|---|
| **没有联机** | 第 1 轮做。但命令 / 快照边界已就位，`logic/` 到时候不用改 |
| **没有正式敌人** | 只有调试面板刷出来的测试敌人 + 地图预置的守军；AI 只做「推进 → 拆挡路的墙」（箭塔不在它的目标列表里，会绕开） |
| **NPC 不会主动索敌建筑** | 刻意与玩家不对称：玩家单位会主动打敌方建筑，NPC 拆建筑仍由 AI 指定（否则推进节奏会被改掉） |
| **没有胜负条件** | 单机大本营血量保底 1，永远打不掉（`pvp` 那套开关与判定已实现，等联机打开） |
| **建造 / 招募都免费** | `config.economy.enabled = false`；填上 `cost` 再打开即可启用消耗（招募的 `cost` 在 `config.recruit.list` 里） |
| **可招募单位只有占位一项** | `config.recruit.list` 现在只有「占位单位」，招出来是亲兵那一套数值；正式兵种表要等玩法定下来 |
| **操作反馈暂无可视出口** | 事件日志按需求删掉了，所以「建造模式已切换 / 招募失败 / 这一格不能建」这类提示**目前看不到**；`input_controller.toast` 信号留着，补一个浮动提示即可（见 [`route.md`](route.md) 第十节） |
| **只有大本营 / 箭塔是「本体阻挡」** | 城墙仍然是整格（`body_scale = 1.0`）；缝宽完全由 `body_scale` 决定，调大就堵死、调小就更宽松（`config.json` 里有说明） |
| **小地图只是占位** | 左下 400×400 是灰底 + 「地图」二字，没有画地形/单位，也不能点击跳转 |
| **阵营 / 盾徽 / 旗帜没做** | 底栏那个 150 宽的面板只有占位文字（需求：先不做） |
| **科技页、设置按钮点不动** | 按需求留着位置，不做功能 |
| **HUD 压住地图下方约 400px** | 底栏 + 小地图占位把屏幕下沿盖住了；镜头仍按整个视口夹取，所以贴下沿的单位可能被 HUD 挡住（以后可以做「可视区域偏移」） |
| **区块划分是均分占位** | `data/map_01.json` 现在**仍然**没有 `zones` 网格，所以随游戏发布的那张图还是 6×4 均分；用地图编辑器打开它 → 划好区块 → 导出，游戏就会读真正的区块划分（Godot 侧已就绪，`zone.build_from_map()` 会自动切换） |
| **占位美术** | 圆 = 单位、矩形 = 建筑（尺寸与碰撞本体一致）。换 2.5D/3D 时只动 `view/` |
| **没有地形高低差 / 战争迷雾 / 存档** | 与 HTML 版一致 |
| **大本营会让整个区块瞬间归己方** | 照搬 HTML 版的行为（开关在 `config.zone.zone_owned_by_building`，副作用见那里的注释） |
