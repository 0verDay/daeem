## 怎么跑

```powershell
# 一键跑完全部无头测试（靠退出码判定成败）
powershell -ExecutionPolicy Bypass -File tools/run-tests.ps1

# 只做语法 / 编译检查（比跑测试更早、更准地报行号）
powershell -ExecutionPolicy Bypass -File tools/check-syntax.ps1

# 装中文字体（每台机器跑一次；不装则 HUD 里中文显示成方框）
powershell -ExecutionPolicy Bypass -File tools/setup-font.ps1

# 改了 C# 之后必须先构建，否则跑的还是旧程序集
dotnet build daeem.csproj -c Debug

# 用编辑器打开工程
& 'C:\D\GodotEngine\gd4.7.2mono\Godot_v4.7.2-stable_mono_win64_console.exe' --path . --editor

# 直接跑游戏（不导出 exe）
& 'C:\D\GodotEngine\gd4.7.2mono\Godot_v4.7.2-stable_mono_win64_console.exe' --path .
```

> `tools/` 里的 `.ps1` **只用 ASCII 书写**（中文 Windows 的 PowerShell 5.1 会把无 BOM 的
> `.ps1` 当 GBK 解码并直接解析失败）。中文说明在 [`../daeem/tools/README-tools.md`](../daeem/tools/README-tools.md)，
> 原因见 [`pitfalls.md`](pitfalls.md) 4.4。

## 三句话记住本轮的取舍

1. **纯 2D、只做单机**，但逻辑层现在就分出「命令 / 快照」边界，为第 1 轮的互联网联机铺路。
   本轮**没有写一行联机代码**，但 `command_processor` / `snapshot` 已经就位并有测试。
2. **逻辑与渲染分离**：`logic/` 是纯 `RefCounted`（不碰场景树、不读输入），`view/` 只读状态 + 发命令。
   代价是多写一层同步代码，回报是逻辑能无头跑（1606 项断言靠的就是这个）。
3. **数值全进 `data/config.json`，地图全进 `data/test_map.json`**；代码里不写字面量。
   区划（区块）的中心、人口、产能属于**地图数据**，所以它们写在 `test_map.json` 的
   `zone_list` 里，由地图编辑器可视化编辑（见 [`route.md`](route.md) 第十四节）。

## 操作方式（与 HTML 版一致）

| 操作 | 说明 |
|---|---|
| `1` / `2` / `3` | 快速选中三个将领（并把镜头移过去） |
| 左键 | 选中将领 / 建筑；`Shift` + 左键多选 |
| **右键单击敌人 / 敌方建筑** | **优先攻击它**（一路追上去打，不受追击上限约束；建筑是先靠近再拆） |
| **右键双击**任意位置 | **行军攻击**（等价 SC2 按 A）：走到该点，路上遇敌就停下来打，打完了继续走 |
| 右键单击空地 | 命令选中单位移动到**鼠标所指的位置**（点到哪走到哪；点到山 / 敌方城墙时自动走到最近可达处）。**遇敌不停**，且会中断当前交战 |
| （自动） | **警戒**：单位静止且没有目标时自动索敌并主动接敌，不需要玩家操作 |
| **左侧「部队」列表** | 点一行 = 选中那支队伍（只选中，**镜头不动**）；空槽显示「…」且点了没反应 |
| **详细信息栏（底栏 1030×240）** | 比例照参考图（左 37.5 : 右 62.5）。**左栏 = 1 + 3×3 = 10 个格子**：左上第 1 格 = **当前展开 / 唯一选中那支部队的将领格**（40×40 方框 + 右边两行「将领真名 / x÷y」，13 号字、与方框垂直居中）；下面 **3×3 = 9 格**同一种格子——**选中多支部队**时画**其余**部队的将领（点一格 = **换展开哪一支**，右栏跟着变成它的将领，**不改选中**；展开的那支不重复出现；一支都没选中时整块空着），**只选中一支**时画这支部队的**单位**（第一个就是将领本人，点一格 = 右栏切到那个单位；超过 9 个用**滚轮翻页**，一次一页）。右栏（照参考图逐像素）：**100×100 头像** + 单位名称（29 号字）+ **三个 30×30 的 buff 占位** + 「详细信息」（**606×90，横跨整栏**）。右栏显示谁**按「怎么选中的」分**：**拖拽框选** → 展开那支部队的将领；**鼠标单击某个单位** → 显示点到的那个单位；点左栏单位格 → 切到那个单位。⚠️ 这里**没有**资源行（粮食 / 黄金按手玩要求删了） |
| **命令卡（右下 3×3）** | 内容随右侧页签切换：**建筑页** Q=城墙 / W=箭塔（进建造模式，再点一次退出），**单位页** Q=占位单位（**排进招募队列**，见下一条） |
| **页签（单位 / 建筑 / 科技）** | 单位、建筑用来切命令卡；**科技本轮点不动**；右上角**设置**也点不动 |
| **招募（单位页 Q）** | 先选中一个将领（`1`/`2`/`3`）→ 点 Q 格或按 `Q`：**排进它的招募队列**（入队即扣 **50 粮 / 50 金 / 该区划 1 人口**），读条 **10 秒**后在该将领所在格的**中心**生成。队列最多 **5 个**（1 个正在读条 + 4 个排队），在详细信息**右栏右上角**用「1 大 + 4 小」五个格子显示。⚠️ 将领必须站在**己方区划**里；⚠️ **读条期间它固定在原地**（不能移动、不能攻击），而且**它和它辖下的部队都不接受指令**（只跑警戒逻辑，见下一条） |
| **取消招募** | **点那五个格子中的某一格** = 取消那一格（全额退款），**后面的队列自动前移**；点大格子就是取消正在读条的那个。生成完成时如果你**还选中着那个将领**，新兵也会被一起选中 |
| **招募期间的整队锁定** | 将领一开始招募，**它和它名下的全部部队**都不接移动 / 攻击命令（已经在下达路上的旧命令会**就地收队**），部队只会自己警戒（靠近的敌人照样打）。右键点下去时底栏会红字说明「将领正在招募单位」，并且**不会**画出没人会走的移动标记 |
| `B` / `T` | 进城墙 / 箭塔建造模式（与命令卡的 Q / W 同一条路），左键放置，右键或 `Esc` 退出 |
| `X` / `Delete` | 拆除选中建筑（大本营不可拆） |
| **方向键** | 平移视野 |
| 鼠标推到屏幕边缘 | 滚屏（**屏幕最外圈永远是滚屏区**，鼠标停在可点控件**靠里**的部分时不会滚） |
| 滚轮 | **以光标为锚点**缩放；`F` 适应视野；`Home` 回大本营 |
| `N` / `P` / `E` / `G` | 显示隐藏区块名 / 暂停 / 刷一个测试敌人 / 坐标调试准星 |

> ⚠️ `W` / `A` / `S` / `D` **不再平移镜头** —— 它们被命令卡的九个格子占用了
> （否则「建筑页按 W 建箭塔」和「W 向上平移」会打架，见 [`route.md`](route.md) 9.3）。

## 本轮已知限制（有意不做）

| 限制 | 说明 |
|---|---|
| **没有联机** | 第 1 轮做。但命令 / 快照边界已就位，`logic/` 到时候不用改 |
| **没有正式敌人** | 只有调试面板刷出来的测试敌人 + 地图预置的守军；AI 只做「推进 → 拆挡路的墙」（箭塔不在它的目标列表里，会绕开） |
| **NPC 不会主动索敌建筑** | 刻意与玩家不对称：玩家单位会主动打敌方建筑，NPC 拆建筑仍由 AI 指定（否则推进节奏会被改掉） |
| **没有胜负条件** | 单机大本营血量保底 1，永远打不掉（`pvp` 那套开关与判定已实现，等联机打开） |
| **建造仍然免费** | `config.economy.enabled = false` 只管**建造**（城墙 / 箭塔的 `cost` 现在还是 0）。★ **招募不免费**：它的 50 粮 / 50 金是玩法需求，走的是**无条件扣费**那条路（`economy.spend`），不受这个总开关影响 |
| **可招募单位只有占位一项** | `config.recruit.list` 现在只有「占位单位」，招出来是亲兵那一套数值；正式兵种表要等玩法定下来 |
| **取消只能一格一格点** | 点某一格 = 取消那一格（全额退款 + 后方前移）；**没有**「一键清空队列」，也没有键盘快捷键（要加就再发一条 `recruit_cancel`） |
| **操作反馈只有一处** | 详细信息面板最下面那行红字（约 `config.ui.notice_sec` = 2 秒）只显示**招募被拒 / 指令被拒**的原因；建造模式切换 / 「这一格不能建」这类提示仍然看不到（事件都在，缺的是显示窗口，见 [`route.md`](route.md) 第十节） |
| **所有图标都是字** | 头像 / 单位方块里写的是「将 / 兵」（`unit_roster` / `troop_grid`），右栏那三个 buff 方框写的是 `buff1/2/3` —— **没有实际 buff 系统**，纯占位（手玩原话：「可以先做几个无效果的 buff 凑数」） |
| **详细信息栏不再显示资源** | 按手玩要求把「阵营 + 粮食 + 黄金」那一行删掉了（参考图上没有）；界面暂时没有别的窗口显示资源 |
| **单选时单位超过 9 个要翻页** | 左栏下半只有 3×3 = 9 格，而编制上限是 11 ⇒ 单选一支队伍时看第 10、11 个单位得把鼠标放在网格上**滚轮翻页**（左下角画「1/2」+ 淡色箭头；一次一页 9 格） |
| **只有大本营 / 箭塔是「本体阻挡」** | 城墙仍然是整格（`body_scale = 1.0`）；缝宽完全由 `body_scale` 决定，调大就堵死、调小就更宽松（`config.json` 里有说明） |
| **小地图只是占位** | 左下 400×400 是灰底 + 「地图」二字，没有画地形/单位，也不能点击跳转 |
| **阵营 / 盾徽 / 旗帜没做** | 底栏那个 150 宽的面板只有占位文字（需求：先不做） |
| **科技页、设置按钮点不动** | 按需求留着位置，不做功能 |
| **HUD 压住地图下方约 400px** | 底栏 + 小地图占位把屏幕下沿盖住了；镜头仍按整个视口夹取，所以贴下沿的单位可能被 HUD 挡住（以后可以做「可视区域偏移」） |
| **区块划分是均分占位** | `data/test_map.json` 现在**已经带 `zones` 网格与 14 个区划中心**（由地图编辑器导出）；想改成自己的形状就用编辑器打开它 → 划区块 / 挪中心 / 配产能 → 导出 |
| **人口只有招募在消耗** | 区划人口按人口产能累积（无主区划也涨），**目前唯一的消耗是招募单位（每个 1 人口）**；它仍然不进 HUD 的资源，只在点开区划中心时看得到 |
| **区划中心不参与玩法** | 它目前只是「中立障碍 + 点开看详情的入口」：不产出、不防守、不提供视野。要不要让它成为「占了这个中心才算占了区划」的判定点是下一步的设计问题 |
| **占位美术** | 圆 = 单位、矩形 = 建筑（尺寸与碰撞本体一致）、菱形 = 区划中心。换 2.5D/3D 时只动 `view/` |
| **没有地形高低差 / 战争迷雾 / 存档** | 与 HTML 版一致 |
| **大本营会让整个区块瞬间归己方** | 照搬 HTML 版的行为（开关在 `config.zone.zone_owned_by_building`，副作用见那里的注释） |
