## 三句话记住本轮的取舍

1. **纯 2D、只做单机**，但逻辑层现在就分出「命令 / 快照」边界，为第 1 轮的互联网联机铺路。
   本轮**没有写一行联机代码**，但 `command_processor` / `snapshot` 已经就位并有测试。
2. **逻辑与渲染分离**：`logic/` 是纯 `RefCounted`（不碰场景树、不读输入），`view/` 只读状态 + 发命令。
   代价是多写一层同步代码，回报是逻辑能无头跑（1606 项断言靠的就是这个）。
3. **数值全进 `data/config.json`，地图全进 `data/maps/<id>/map.json`**；代码里不写字面量。
   ★ **一个地图一个目录**，目录名就是地图的 id；地图 json 里的 `name` 是开场主界面
   那条**地图选择条**上显示的名字（不写就用目录名）。选择条**不是**在配置里列清单 ——
   `logic/map_library.gd` 扫描 `data/maps/` 自动给出选项，所以**加一张图 = 加一个目录**，
   代码与配置都不用动（见 [`architecture.md`](architecture.md) 第二节的目录结构）。
   区划（区块）的中心、人口、产能属于**地图数据**，所以它们写在
   `map.json` 的 `zone_list` 里，由地图编辑器可视化编辑（见 [`route.md`](route.md) 第十四节）。

| **命令卡（右下 3×3）** | 内容随右侧页签切换：**操作页** Q=移动 / W=攻击 / E=行军 / A=停止（点了进**命令模式**，再左键点地图 / 点敌人下达；右键或 `Esc` 退出），**单位页** Q/W/E = 长枪兵 / 长弓兵 / 骑手（**排进选中将领的招募队列**），**建筑页** Q=城墙 / W=箭塔（进建造模式，再点一次退出），**招募页** Q/W/E = 三个占位将领（**排进这个区划的招募队列**），**科技页**本版空着 |

| **取消招募** | **点那五个格子中的某一格** = 取消那一格（全额退款），**后面的队列自动前移**；点大格子就是取消正在读条的那个。鼠标停到有内容的格子上会**描红框 + 右上角出现「×」**（哪些格子能点、点了取消谁一眼可见；汇总带与空格子点了什么都不发生）。生成完成时如果你**还选中着那个将领**，新兵也会被一起选中 |
| **招募期间的整队锁定** | 将领一开始招募，**它和它名下的全部部队**都不接移动 / 攻击命令（已经在下达路上的旧命令会**就地收队**），部队只会自己警戒（靠近的敌人照样打）。右键点下去时底栏会红字说明「将领正在招募单位」，并且**不会**画出没人会走的移动标记 |
| `B` / `T` | 进城墙 / 箭塔建造模式（与命令卡的 Q / W 同一条路），左键放置，右键或 `Esc` 退出 |
| `X` / `Delete` | 拆除选中建筑（大本营不可拆） |
| **方向键** | 平移视野 |
| 鼠标推到屏幕边缘 | 滚屏（**屏幕最外圈永远是滚屏区**，鼠标停在可点控件**靠里**的部分时不会滚） |
| 滚轮 | **以光标为锚点**缩放；`F` 适应视野；`Home` 回大本营。⚠️ **鼠标停在底栏（详细信息 / 阵营 / 命令卡 / 页签）上时不缩放**（第六轮，用户需求）—— 移出底栏立刻恢复；**左下小地图不算 ui 栏**，停在它上面照旧缩放 |
| `N` / `P` / `E` / `G` | 显示隐藏区块名 / 暂停 / 刷一个测试敌人 / 坐标调试准星 |

> ⚠️ `W` / `A` / `S` / `D` **不再平移镜头** —— 它们被命令卡的九个格子占用了
> （否则「建筑页按 W 建箭塔」和「W 向上平移」会打架，见 [`route.md`](route.md) 9.3）。
