# 操作方式（2026.11.15 第三轮：鼠标回退经典 RTS）

> 范围：**PC 鼠标 + 键盘**。触屏**完全没动**（见 `mobile.md` 第 6 节）。
> 这一轮把 2026.11.14 的「操作牌 + 左键拖视角」整套回退掉：
> 部队不再有「操作」页，移动 / 锁定攻击 / 行军全部回到**右键**。

---

## 1. 鼠标

| 手势 | 行为 | 实现 |
|---|---|---|
| **左键单击** | 选中 / 退选（单位、建筑、区划中心；点空地不改选中） | `input_controller._on_left_click()`，在**松手**时判定 |
| **左键拖拽** | **框选**：拖出矩形，松手按屏幕矩形选中框内己方单位（框内没单位时收己方建筑） | `_begin_box()` / `_finish_box()` → `box_select_screen()` |
| **右键拖拽** | **拖视角**：移动超过 `RIGHT_PAN_MIN_PX`（6px）才开始拖；松手带惯性滑行 | `_begin_right_drag()` / `_finish_right_drag()` + `_start_pan_fling()` |
| **右键单击** | 空地 = **移动**；敌人 / 敌方建筑 = **锁定攻击**（一路追着打，目标死了自动完成） | `_on_right_click(false)` → `_issue_order_click()` |
| **右键双击** | **行军攻击**（`attack_move`）：走到该点，路上遇敌就停下打，打完继续走 | `_on_right_click(true)`（Godot 的 `double_click`） |
| 滚轮 | 缩放 | 不变 |
| 中键 | **不再参与视角**（用户口径：只保留右键拖视角） | — |

**单击 / 拖拽的分界**：右键移动 < 6px = 单击（下令）；≥ 6px = 拖视角（**松手不下令**）。
左键走 config 的 `ui.drag_select_min_px`（默认 6px）：小于它算单击，大于它算框选。

**落在 UI 上**（手牌 / 页签 / 详细面板 / 选项页）：事件归 GUI，不会开始框选或拖视角；
手势中途划到 UI 上时，`game_scene3d._input()` 会把移动 / 抬起补一遍（见
`has_active_gesture()`），框 / 视角不会卡住。

---

## 2. 键盘

- `Esc`：一层层取消（框选 / 命令模式 / 选中 / 打开选项页）。
- `Tab` / `Shift+Tab`：切换右下页签（只有一页时不切）。
- `Q W E A S D ...`：命令卡九宫格对应格子的快捷键（建筑页 = 建筑，单位页 = 招募）。
- `1..6`：右侧编队标签选部队；`空格` / 方向键：镜头。
- **没有**「停止」快捷键（见下）。

---

## 3. 这一轮删掉的东西

| 删除项 | 原因 / 替代 |
|---|---|
| 部队的「操作」页签（移动 / 攻击 / 行军 / 停止四张牌） | 用户口径：不需要保留部队操作栏；右键直接下令 |
| 操作牌的拖拽 + 旗帜虚影 + 吸附 | 同上；`overlay.order_ghost_*` 与 `game_scene._sync_order_ghost()` 一并删除 |
| 操作牌的 3 秒冷却（含牌面暗纱进度条） | 用户口径：取消单位操作冷却 |
| 「停止」指令的 UI（按钮 / 快捷键） | 用户口径：不需要再有「停止」 |
| 濒死将领的「再起 / 取消再起 / 召回」操作页 | 改为**自动再起**（见第 4 节） |

> 逻辑层的 `stop` / `revive` / `recall` 命令**还在**（协议 / AI / 测试可用），
> 只是玩家界面不再提供入口。`revive` 仍然免费，`channel_sec = 0`。

---

## 4. 将领自动再起

用户口径：「将领在达到条件后会自动立刻再起，不消耗资源、无读条时间」。

- **条件不变**：血量回复到 `revive.ready_ratio`（默认 10%）。
- **自动**：`world._tick_auto_revive()` 每帧检查，满足条件就调 `start_revive()`；
  `revive.channel_sec = 0` ⇒ 下一帧完成（`unit.start_revive` 用 0.01s 哨兵保证
  「正在再起」这一帧可见、且能进快照）。
- **不消耗资源**：原本就免费，没有 `revive.cost`。
- 读条期间仍然暂停「旗下部队全灭」判定（原规则不变）。
- 「召回」（静默杀兵 → 阵亡 → 更短重生）不再有 UI 入口；命令接口保留。

---

## 5. 触屏（未改动）

单指拖动 = 视野；双指 = 框选；单击 = 没选中就选中、已选中就下令；双击 = 行军攻击；
长按 UI 格 = 悬停详情。判据见 `view/touch_controller.gd` 与 `mobile.md` 第 6 节。

## 6. 测试

- `tests/test_view.gd`：右键拖拽平移 + 中键不再平移 + 松开后滑行。
- `tests/test_ui.gd`：
  - 选中部队只有「单位」一颗页签；
  - 右键单击空地 = move、右键单击敌人 = attack（带 target_id）、右键双击 = attack_move；
  - 右键拖拽松手**不下令**；
  - 左键拖拽 = 框选（相机不动）、框选期间划到底栏仍继续更新；
  - 快速施法/招募等原有用例。
- `tests/test_friendly_building.gd`：右键友军建筑 = 移动（不是攻击）。
- `tests/test_view3d.gd`：右键单击敌人 → 「指定攻击」标记。
- `tests/test_downed.gd`：血量到 10% 自动再起、无读条、免费、快照往返。
