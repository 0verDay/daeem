## 1. 共同规则（两派一致）

- **招募即时**：单位 / 区划招将都是当场生成，没有队列与读条；只有「招将全局冷却」还在。
- **人口**：每个招募条目扣对应人口，人口从**下单那一刻将领所在的区划**扣；开局所有区划人口为满。
- **编制上限**：每位将领默认 11（+ 大本营 `retinue_cap_bonus`）；单位表里的「编制上限」是基础值。
- **科技**：同时最多启用 **3** 条；按阶每秒扣金 **0.5 / 1 / 2 金/秒**（一/二/三阶），启用即开始扣。
- **兵种大类**：步兵（维护 0.08 粮/秒）、骑兵（0.18）、器械（0.4）；具体单位可覆盖维护费。
- **单位特性**：只作用于单位（对某大类增伤 / 近战或远程减伤 / 免疫击退）；**将领特性**只作用于将领本人 + 旗下所有附属兵。
- **建筑 / 经济 / 升级 / 建造点位**是全局规则，不按派系分表；本文只列两派的单位、科技、将领。
- **起手资源 / 难度**由关卡 `factions[]` 与运行时覆盖决定，不写死在派系表里。

- 所有数值都是 `data/config.json` 的**最终值**；将领的 HP / 攻击 / 射程 / 攻速 / 移速 / 视野若在 `general.stats` 有覆盖，表中已按覆盖值计算，护甲仍取所属兵种。
