联机对战规则（v0.6）

        
    
          
  • 先准备，再开战：进房间后停在准备界面，双方都按 R（或点「✅ 准备」）
              之后，房主宣布开战并倒数 3 秒。只有一个人在场时永远不会开打。
    • 
          
  • 双方各有自己的大本营：房主（p1）在地图中央，客机（p2）在地图右下角，
              相距 10 格。双方开局各有一小段城墙 + 一座箭塔。
    • 
          
  • 阵亡后 8 秒在自家大本营复活，满血。屏幕上会画一个复活倒计时环
              （在你家大本营位置）。所以死一次不用干等，但也杀不光对方。
    • 
          
  • 胜负：打掉对方大本营 = 对方落败。大本营可以被打掉，
              但不能用 X / Delete 拆除。打掉后屏幕中央显示结算。
    • 
          
  • 结算后按 R 或点「↻ 再来一局」回到准备界面，双方再准备就能再打一局
              （不用刷新页面）。
    • 
          
  • 超过 10 分钟按大本营剩余血量比例判胜负，防止无限拖时间。
    • 
          
  • 城墙只挡对手：穿不过对方的墙，但能穿过自己的。要拆墙就派兵去打。
    • 
          
  • 客机看到的结算结果由房主判定后同步过来，所以两边显示一定一致。
    • 
        

        
操作说明

        
    
          
  • 1 / 2 / 3：快速选中三个将领
    • 
          
  • 左键：选中将领 / 选中建筑；Shift + 左键多选
    • 
          
  • 右键：命令选中将领移动到鼠标所指的位置（点到哪走到哪；点到山/城墙/建筑时自动走到最近的可达处）
    • 
          
  • 自动战斗：单位静止且没有目标时，会自动警戒周围 4 格内的敌方单位 —— 先移动靠近，进入攻击距离后再开火（红色虚线环=交战目标，头顶小三角=交战中）
    • 
          
  • B / T：进入城墙 / 箭塔建造模式，左键放置，右键或 Esc 退出
    • 
          
  • X / Delete：拆除选中的建筑（大本营不可拆）；选中城墙可以看到它的生命值
    • 
          
  • 鼠标推到视野边缘：平移视角（按住 空格 可临时冻结）；W A S D / 方向键也可平移
    • 
          
  • 滚轮：以光标为锚点缩放；F：缩到看完整张地图；Home：回到大本营
    • 
          
  • N：显示 / 隐藏区块名；P：暂停；E：刷一个测试敌人；H：本帮助
    • 
          
  • G：坐标调试准星（红叉=鼠标所指的点，绿圈=判定出的地块中心，两者必须重合）
    • 
        

        
联机（v0.4）

        
    
          
  • 地址里带 #net=1 才联机：…/rts-prototype.html#net=1。
              不带就是纯单机，和以前完全一样。
    • 
          
  • 第 1 个进房间的人是房主（阵营 p1），他跑权威逻辑；其他人是客机（p2、p3…）。
    • 
          
  • 换一局用 #net=1&room=别的名字；开打前确认双方 room 一致。
    • 
          
  • 客机点下右键后单位会稍后才动（约 150ms：50ms 快照 + 100ms 插值缓冲），
              这是设计使然，不是卡顿。
    • 
          
  • 连不上服务器时会自动退回单机模式并写进事件日志，不会白屏。
    • 
          
  • 房主关掉页面后，服务器会把下一位提升为新房主 —— 这局不会停摆，
              但世界状态会重新同步。
    • 
          
  • 部署与排错见 net/README.md；控制台里用 RTS.netStatus() 看联机状态。
    • 
        

        
本版规则

        
    
          
  • 地图为 24×16 四连通地块，每格 120px（世界尺寸 2880×1920），单位远小于一个地块。
    • 
          
  • 山不可通行、森林减速；单位沿 A* 路线连续平滑移动，终点就是点击位置，不吸附格心。
    • 
          
  • 能走直线就走直线：寻路结果会被拉直（每段直线都做过通行判定），只有绕山 / 绕城墙时才出现拐点。
    • 
          
  • 每个地块最多一个建筑：大本营（开局自带、不可摧毁）／城墙／箭塔。
    • 
          
  • 城墙有血量（默认 300，见 CONFIG.building.wall.hpMax）：敌人被墙挡住时会贴上来一下一下拆（每次 40 点、间隔 1.2s），墙塌了就让出缺口；掉血的墙会显示血条、挨打时整格闪红。
    • 
          
  • 战斗：将领与敌人都有攻击伤害、攻击距离、攻击间隔（数值集中在 CONFIG.combat）；开火时画一条攻击线。
    • 
          
  • 警戒：没有目标且静止的单位会锁定警戒半径内最近的敌方单位，先靠近再攻击；目标跑出追击上限就放弃；右键移动命令会中断交战。
    • 
          
  • 资源 = 己方占领地块数 × 每秒 1 粮食 1 黄金，实时增长。
    • 
          
  • 区块占领（占位规则）：己方将领站在无主区块内 4 秒即可占领整个区块；正在占领时区块会从下往上填充黄色。
    • 
          
  • 本版没有正式敌人，建造不消耗资源，战斗逻辑用调试刷出的测试敌人验证。
